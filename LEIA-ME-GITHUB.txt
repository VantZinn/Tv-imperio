COMO TROCAR OS ARQUIVOS DO SEU GITHUB

1. Extraia Empire_TV_10008_Atualizacao_GitHub.zip no seu aparelho.
2. Envie O CONTEÚDO extraído para a raiz de VantZinn/Tv-imperio.
   Substitua os arquivos com o mesmo nome e mantenha as pastas.
   Não envie só este ZIP: o Render precisa dos arquivos extraídos.
3. Inclua public/, empire-project/ e .github/workflows/gerar-apk.yml.
   O arquivo do workflow substitui o anterior. Se seu gerenciador ocultar
   .github, ative a opção de mostrar arquivos ocultos.
4. Após o commit, aguarde a publicação no Render. Se não houver publicação
   automática, use Manual Deploy > Deploy latest commit no seu serviço.
   O Dockerfile está pronto e npm start continua sendo o comando de início.
5. Para gerar um novo APK: GitHub > Actions > Gerar APK Empire TV > Run workflow.
   Deixe project_url vazio e make_play_bundle desmarcado para o APK de teste.
   O workflow monta o projeto atualizado automaticamente e verifica cada parte.
   O ZIP antigo na raiz não é utilizado quando empire-project/ está presente.

ONDE OS TUTORIAIS APARECEM

Em cada página: Vant: como usar esta página.
Todos juntos: Configurações > Tutoriais.
São 46 assuntos, com quatro passos por assunto, busca, filtros e progresso
salvo. O jogador pode pausar e retomar. Os tutoriais explicam finalidade,
uso, custos, limites e como conferir o resultado, sem gastar os recursos.
As missões iniciais continuam sendo necessárias para concluir a orientação.
